# Decode a message from a Google Doc

25-minute live coding interview exercise for The RealReal.

## Start here (Codespaces — preferred)

1. Open this repository on GitHub.
2. Click **Code → Codespaces → Create codespace on main**.
3. Wait for the post-create install (~1–2 minutes), then open `PROMPT.md` and implement `decode.py`.

## Local fallback (no Docker)

```bash
python3 -m pip install -r requirements.txt
python3 decode.py
```

Python 3.10+ recommended. See `PROMPT.md` for the problem statement and sample document URL.
